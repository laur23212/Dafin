# Rack Focus Bridge

Category: cinematic

What viewer sees: Shot A loses detail as if focus is pulled away while shot B arrives blurred and becomes sharp. Purely image-space defocus; no fake camera tracking.

Controls: Maximum defocus (px), Focus overlap, Focus timing bias.

Caveat: Best for product reveals, inserts and B-roll. Costs 26 texture samples per pixel in a single pass.

All code authored originally for Dafin. No embedded imagery, fonts, logos or commercial assets.
