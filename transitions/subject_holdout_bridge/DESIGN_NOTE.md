# Subject Holdout Bridge

Category: smart-content

What viewer sees: Requires an outgoing clip mask. The next shot replaces the environment while the subject briefly remains, then gracefully fades. If no mask exists, uses a smooth alpha-aware crossfade.

Controls: Subject hold time, Background reveal pace, Mask edge smoothing, Subject lift.

Caveat: Best for interviews, people cutouts, tutorials and narrative handoffs. Needs subject mask on outgoing clip; mask is not automatically detected.

All code authored originally for Dafin. No embedded imagery, fonts, logos or commercial assets.
