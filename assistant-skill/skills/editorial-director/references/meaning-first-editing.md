# Why this cut? A minimal edit-decision protocol

1. State the legitimate viewer goal and what changes in this beat: information, emotion, story, geography, timing or proof.
2. For every proposed edit, state exactly one dominant purpose. A cut is not the purpose; it is a treatment.
3. Ask what viewers would miss if the edit were removed. If nothing, propose a no-effect comparison instead of assuming the edit is wrong.
4. Reaction and silence can communicate more than a cut. An annotation `protect_hold` signals a reviewer concern, not an automatic command.
5. Proof footage and B-roll require native source lookup and truthful context. Unverified annotation IDs are not evidence.
6. Compare the original and revised scene at actual playback speed with audio; do not report aesthetic improvement from structured metadata alone.
