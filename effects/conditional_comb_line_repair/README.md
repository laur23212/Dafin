# Conditional Interlace Comb Minimizer

Spatially repairs strong horizontal line combing on archival interlaced video; local threshold limits unwanted softness.

**Difference from V3/V4:** V3 Vintage and Film Grain stylize old footage, not restoration; no equivalent comb detector in V4.

**Dependency:** none (source pixels).

**Caution:** Cannot reconstruct missing fields or substitute for motion-adaptive temporal deinterlacing.

Native shader source with Inspector-editable parameters. Requires in-app QA.
